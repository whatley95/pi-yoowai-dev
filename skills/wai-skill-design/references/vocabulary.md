# Motion vocabulary

For a naming question, lead with the closest term and a brief explanation. Offer
alternates when the observed effect is ambiguous; do not claim precision without
seeing enough of it. This glossary is a reference, not a requirement to animate.

| Term                               | Meaning                                                                  |
| ---------------------------------- | ------------------------------------------------------------------------ |
| Fade / crossfade                   | Opacity change / overlapping fades between states                        |
| Slide / translate                  | Movement from an edge / position change                                  |
| Scale / pop in                     | Size change / an entrance with slight overshoot                          |
| Reveal / clip-path / mask          | Uncovering content / geometric clipping / alpha masking                  |
| Transform origin                   | Anchor around which a transform operates                                 |
| Origin-aware animation             | Motion anchored to the initiating control                                |
| Morph                              | Continuous change in shape                                               |
| Shared-element transition          | A recognizable element travels/transforms between views                  |
| Layout animation                   | Animated changes to layout position or size                              |
| Direction-aware transition         | Motion direction follows navigation direction                            |
| Stagger / orchestration            | Sequential delays / coordination across multiple elements                |
| Keyframes / interpolation          | Defined animation states / values between states                         |
| Easing / cubic-bezier              | Rate of progress / a curve describing that rate                          |
| Spring                             | Motion responding to a physics-like target rather than only fixed timing |
| Stiffness / damping / mass         | Pull toward target / resistance / simulated inertia                      |
| Momentum / velocity                | Carried motion / speed with direction                                    |
| Rubber-banding                     | Increasing resistance and return beyond a boundary                       |
| Interruptible animation            | Motion that responds coherently to new input mid-flight                  |
| Swipe to dismiss / drag to reorder | Gesture dismissal / rearranging items by dragging                        |
| Hold to confirm                    | Progress feedback for a deliberate held action                           |
| Scroll reveal / parallax           | Entry on visibility / layers moving at different rates                   |
| View transition                    | Browser-assisted transition between rendered states                      |
| Marquee / loop / yoyo              | Continuous scrolling / repetition / alternating direction                |
| Shimmer / skeleton                 | Loading sheen / placeholder layout                                       |
| Number ticker / tabular numbers    | Animated digits / equal-width digit typography                           |
| Jank / compositing                 | Visible rendering interruption / combining rendered layers               |
| Reduced motion                     | A preference for less or no potentially disturbing motion                |

For the complete original glossary, use `wai_design_ref` topic
`animation-vocabulary`; continue from its returned `nextOffset` if the page is limited.
